## hp ±1/±2 무효 구문 16곳 — 실제 효과 부여 (보류 중)

### 배경

리팩토링 전 `defineShims()`는 `S.hp`에 setter를 걸어 legacy 대사 데이터를 새 상태에
연결했다. 그 setter는 **변화량의 절댓값이 3 이상일 때만** 상처를 움직였다.

```js
var cur = Math.max(0, (MAXHP - this.wounds)) * 4;   // 0 wounds -> 16
var d = v - cur;
if (d <= -3)      this.wounds = Math.min(MAXHP, this.wounds + 1);   // 상처 +1
else if (d >= 3)  this.wounds = Math.max(0, this.wounds - 1);       // 상처 -1
// |d| < 3 이면 아무 일도 일어나지 않는다
```

따라서 `S.hp+=1`, `S.hp+=2`, `S.hp-=2`는 **호출되어도 아무 효과가 없었다**. 결과
텍스트는 `(목숨 회복)` 또는 `(작은 상처)`를 약속하지만 실제로는 상태가 변하지
않는다. 1단계(`febc14b`)는 순수 구조 변경이 원칙이었으므로 동작을 그대로 보존했다 —
무효 구문은 삭제했고 한국어 텍스트는 손대지 않았다. **현재 게임 동작은 리팩토링
이전과 완전히 동일하다.**

### 남은 작업

아래 16곳에 실제 효과를 부여할지 결정한다. 부여한다면:

- `(목숨 회복)` 9곳 → `if(S.wounds>0)S.wounds--;`
- `(작은 상처)` 7곳 → `if(S.wounds<MAXHP)S.wounds++;`

**주의:** 이는 순수 리팩토링이 아니라 **밸런스 변경**이다. `MAXHP`가 4뿐이라 지금
무효인 피해 7건이 실제 상처가 되면 난이도가 크게 오른다. 회복 9건이 이를 일부
상쇄하지만, 회복은 대부분 우호적 분기에 몰려 있고 피해는 적대적 분기에 몰려 있어
공격적인 플레이가 훨씬 불리해진다. 적용한다면 플레이 테스트가 필요하다.

## moodTail()이 항상 빈 문자열을 반환한다 (2단계에서 발견, 동작 보존)

`STORIES`의 intro 5곳이 `intro:"…" + moodTail()` 형태로 되어 있다. 이는 함수가 아니라
**문자열 연결**이므로 `STORIES`가 만들어지는 시점에 딱 한 번 평가된다. 그 시점의
`S.day`는 항상 `1`이고, `moodTail()`은 다음과 같다.

```js
function moodTail(){
  if(S.day<=3) return "";
  if(S.day<=4) return "\n요즘은 다들 예민해졌다. …";
  return "\n며칠 사이 사람이 변했다. …";
}
```

따라서 **`""`만 반환되며, day 4+ / day 5+ 분기의 두 문장은 게임에서 한 번도 나오지
않는다.** 날이 갈수록 NPC 소개문이 어두워지도록 의도한 장치가 작동하지 않는 셈이다.

2단계는 순수 구조 변경이므로 그대로 보존했다 — `data/dialogue.js`의
`createStories(S, moodTail)`도 로드 시점에 한 번 호출되어 결과가 동일하다.

되살리려면 `intro`를 문자열 대신 함수(또는 게터)로 바꾸고 호출부
(`startBattle`의 `st.intro`)에서 평가해야 한다. 이것도 **텍스트가 새로 노출되는
동작 변경**이므로 별도 결정이 필요하다.

관련 위치: `src/data/dialogue.js`의 `medic`, `smith`, `farmer`, `sleeper`, `deserter`
5개 스토리 intro.

## S.hunger-=24 반올림 불일치 (수정 안 함 — 가독성 우선)

`S.food=Math.max(0,S.food-3)` 2곳(`가진 걸 내주고 사과한다`, `가진 걸 내주고 물러선다`)을
`S.hunger-=24`로 옮겼다. shim의 정확한 동작은
`S.hunger -= Math.min(24, Math.round(S.hunger/8)*8)`이었다.

차이는 `S.hunger`가 17~19인 구간뿐이며, 그 경우 결과가 0 대신 1~3이 된다. 100점
척도에서 최대 3점 차이이고 굶주림 직전 구간에서만 발생한다. 정확히 보존하면 shim의
반올림 왕복 부작용을 그대로 옮겨오게 되어 가독성을 택했다.
